Chapter 7

Describe the purpose of a mutex

protects shared resources by allowing ownership of the shared resource

What is priority inversion?  How does priority inheritance solve this problem?

A high priority task can be blocked by a lower priority task because of the 
mutex. allowing a different task to be ran than those two.

inheritance fixes this by letting the low priority have the high priority, which
then it can finish the task and release the mutex.
